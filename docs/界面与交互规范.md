# 界面与交互规范

适用于设置页、工作区顶栏、侧栏、快捷应用弹窗和过渡画面。界面层运行在 Android Activity 或 SystemUI 内。工程约束以[项目结构与代码规范](项目结构与代码规范.md)为准。

## 组件边界

| 区域 | 优先复用 | 职责 |
| --- | --- | --- |
| 设置 | `WorkspaceSettingsPage`、三组 `*Diagram` | 选项、图示和选中状态 |
| 顶栏 | `TopBar`、`WorkspaceClock`、`IconButton` | 时间、固定操作和可用状态 |
| 快捷应用 | `QuickAppRail`、`QuickAppPicker`、`PinnedAppEditor` | 应用列表、已打开标记和编辑 |
| 顶栏配置 | `ShortcutManagementPage`、`ShortcutEditor`、`PinnedAppEditor` | 设置子页、选择草稿、搜索、排序和显式保存 |
| 工作区外观 | `WorkspaceChrome`、`HyperOsStyle`、`WorkspaceDividers` | 底板、配色、模糊和分隔线 |
| 顶部内容 | `TopPresentationController`、`VideoPane`、`TopTaskPane` | 视频与手动置顶任务的呈现 |
| 过渡 | `WorkspaceTransition`、`TopTaskTransition`、`TransitionSession` | 时间线、取消和场景有效性 |

视图负责绘制与输入，任务归属和系统接口交给宿主或平台层。新增同类界面先复用现有组件，不另建一套颜色、图标或动画曲线。

## 视觉

- 跟随系统深浅色模式，复用 `HyperOsStyle` 和现有壁纸采样；夜间使用较深的模糊底板。
- 顶部文字和图标按各自背景明暗取黑色或白色；禁用态只表达不可操作，不能与选中态混用。
- 顶栏五个图标共用 24 单位画布、3..21 视觉边界与 2.1 线宽。修改轮廓时同时检查视觉中心和触摸区域。
- 设置项标题使用 16sp、说明使用 12sp，文本与开关之间保留 16dp。先缩短文案，再处理必要换行。
- 手势、交换方式、横屏显示三组图示共用卡片结构、206dp 图高、配色和点击区域。
- 已选快捷应用直接展示应用图标，保持小间距，不额外添加彩色外缘或玻璃底板。
- 内容首格使用与应用图标相同的 38dp 彩色图标；内容、快捷应用编辑及分享入口编辑弹窗共用 `WorkspacePopupStyle` 的 420dp 最大宽、620dp／屏高72%最大高、28dp圆角与玻璃材质。
- 尺寸使用 dp、文字使用 sp；系统栏、挖孔与横屏位置由现有几何组件计算，禁止按单台手机写死像素。

## 交互与文案

| 场景 | 规则 |
| --- | --- |
| 空小窗 | 展示「＋」，表示收纳主窗应用 |
| 有内容的小窗 | 点击交换；向所在侧的屏幕外滑动移出，保留应用任务 |
| 顶部内容区 | 展示视频或手动置顶任务，不展示空小窗和「＋」样式 |
| 置顶按钮 | 主窗应用为竖屏时禁用，横屏且满足接入条件时启用 |
| 快捷应用 | 绿色小点只代表工作区主窗或小窗中的应用；手动固定顺序优先 |
| 快捷应用编辑 | 拖动在本次编辑中生效，取消恢复原顺序，确认后保存 |
| 快捷栏配置入口 | 仅在设置中管理快捷应用与分享入口，内容弹窗不显示配置入口，顶栏长按不打开编辑器 |
| 文件页 | 只展示文件列表与元信息；长按拖曳，多选后可批量分享，不打开文件预览 |
| 主窗内容补充 | 支持标准文字选区菜单「拖曳到一步」；内容面板的「截取主窗图片」由用户框选画面后长按拖出 |
| 视频遮挡顶栏 | 内容拖曳时临时显示独立分享条，拖曳结束移除，不改变视频或顶部任务的位置 |
| 设置选项 | 真实保存项与选中态一致，自动保存时明确写「选择后自动保存」 |

统一使用「工作区」「主窗」「小窗」「顶栏」。用户说明描述操作与结果，不展示 Binder、Surface、事务等实现术语。
图标按钮要有语义描述；隐藏的控件不得继续拦截输入。视频与手动置顶的退出控件复用一致的大小、间距和风格。

## 动画

1. 工作区进入、退出使用共享时钟起点和运动规范，主窗与侧栏位移保持对应；加号和应用内容随侧栏整体滑动。
2. 壁纸托底保持物理屏幕坐标，主窗移动期间不得暴露空白或黑色底层。不要用调整速度掩盖几何缺口。
3. 顶部接入先准备目标尺寸和内容帧，再淡入覆盖时间、日期和按钮；退出时同步移除退出控件并淡出恢复原内容。
4. 视频比例变化时按所选 fit / fill 策略裁剪，顶部内容区保持完整遮挡和输入隔离，不能透出或点到下面的快捷应用。
5. 取消、换边、快速连续点击或退出后，旧动画回调不得继续写入新场景。
6. 锁屏与亮屏由统一交接协议控制主窗、顶栏和侧栏显示，不各自启动独立的恢复动画。
7. 分享栏使用 `SHARE_RAIL_MS`（480ms），应用行与分享行按立方体相邻面共棱投影旋转。内容首格仅在应用面显示，分享面从首格起排列分享入口，不预留内容按钮的位置。分享功能图标带蓝色箭头角标，整条分享面使用主题强调色混合底色，命中坐标使用同一投影矩阵的逆变换。
8. 内容拖曳影子使用白框缩略卡与顶部三角指针，指针尖端对应真实投递坐标；文字、文件显示摘要，多选显示数量。命中分享入口时放大至1.14倍并轻微回弹，离开或结束时恢复，不逐帧重启动画。

系统提交协议见[系统与平台规范](系统与平台规范.md)。视图动画结束不等于原生窗口事务已经提交。

## 刷新与资源

`ChromeWarmup` 在主线程空闲时准备未挂载的顶栏，覆盖时钟、日期、图标与布局。只做一次最大 512×512 的软件预绘制并立即回收临时位图；硬件图标不支持软件绘制时保留测量结果。首次使用绑定真实窗口 Context 和监听器，之后不补货；用户、字体、语言、深浅色及尺寸不匹配时重新创建。预热不注册时钟广播、媒体回调或刷新计时器。

预热视图的操作回调必须在点击时读取当前监听器，不能用绑定方法引用保存预热监听器。回归测试须执行真实按钮构造与点击回调，单独验证缓存字段已替换不足以证明按钮可用。

- 已打开标记合并任务变化事件后刷新，稳定时每 30 秒兜底；隐藏、锁屏和 detach 时取消调度。
- 应用列表、壁纸和统计查询复用已有异步加载及缓存，不放入绘制方法或每帧回调。
- 配置变化更新现有视图；关闭弹窗时恢复其借用的层级、灵动岛显示状态和输入资源。
- 新控件必须能适应字体缩放、长应用名、深浅色与手机／平板布局；不以裁掉文字解决开关挤压。

## 验收

检查深浅色、左右布局、横竖屏、长文本和字体缩放。连续进入／退出、快速交换、锁屏解锁、视频尺寸变化及弹窗中截图时，画面和输入都必须一致。
离线绘制或流程测试不能替代真机逐帧和触摸验证；个人截图与设备日志仅放在被忽略的本地目录。
