# 界面与交互规范

适用于设置页、工作区顶栏、侧栏、快捷应用弹窗和过渡画面。界面层运行在 Android Activity 或 SystemUI 内。工程约束以[项目结构与代码规范](项目结构与代码规范.md)为准。

## 组件边界

| 区域 | 优先复用 | 职责 |
| --- | --- | --- |
| 设置 | `WorkspaceSettingsPage`、三组 `*Diagram` | 选项、图示和选中状态 |
| 顶栏 | `TopBar`、`WorkspaceClock`、`IconButton` | 时间、固定操作和可用状态 |
| 快捷应用 | `QuickAppRail`、`PinnedAppEditor` | 应用列表、已打开标记和编辑 |
| 顶栏配置 | `ShortcutManagementPage`、`ShortcutSettingsContent`、`PinnedAppEditor` | 设置子页、搜索、排序和即时保存 |
| 工作区外观 | `WorkspaceChrome`、`HyperOsStyle`、`WorkspaceDividers` | 底板、配色、模糊和分隔线 |
| 顶部内容 | `TopPresentationController`、`VideoPane`、`TopTaskPane` | 视频与手动置顶任务的呈现 |
| 过渡 | `WorkspaceTransition`、`TopTaskTransition`、`TransitionSession` | 时间线、取消和场景有效性 |

视图负责绘制与输入，任务归属和系统接口交给宿主或平台层。新增同类界面先复用现有组件，不另建一套颜色、图标或动画曲线。

## 视觉

- 跟随系统深浅色模式，复用 `HyperOsStyle` 和现有壁纸采样；夜间使用较深的模糊底板。
- 顶部文字和图标按各自背景明暗取黑色或白色；禁用态只表达不可操作，不能与选中态混用。
- 顶栏六个图标共用 24 单位画布、3..21 视觉边界与 2.1 线宽。修改轮廓时同时检查视觉中心和触摸区域。
- 设置项标题使用 16sp、说明使用 12sp，文本与开关之间保留 16dp。先缩短文案，再处理必要换行。
- 弹窗标题使用 16sp，正文、菜单、搜索栏和文字按钮使用 14sp，辅助说明使用 12sp，文件与剪贴板元数据使用 11sp。文字按钮复用 44dp 高度和 10dp 圆角，更多菜单复用竖排三点和 16dp 圆角。
- 手势、交换方式、横屏显示三组图示共用卡片结构、206dp 图高、配色和点击区域。
- 已选快捷应用直接展示应用图标，保持小间距，不额外添加彩色外缘或玻璃底板。
- 内容首格使用 34dp 彩色图标，应用栏图标为 35dp。内容弹窗复用 `WorkspacePopupStyle` 的 360dp 最大宽、500dp／屏高60%最大高、14dp内边距、28dp圆角与玻璃材质。
- 内容图片网格为三列，相邻图片保留4dp间隔、8dp圆角；单元格宽度扣除边距，文件行仍占满内容宽度。每格无障碍描述应带相对时间及选择状态，不能所有图片共用同一句。
- 当前剪贴板类型不支持时，只在内容区显示行内说明；历史记录仍可浏览和拖曳，不能因此把整页替换成错误空态。
- 尺寸使用 dp、文字使用 sp；系统栏、挖孔与横屏位置由现有几何组件计算，禁止按单台手机写死像素。

## 交互与文案

| 场景 | 规则 |
| --- | --- |
| 空小窗 | 展示「＋」，表示收纳主窗应用 |
| 有内容的小窗 | 点击交换；向所在侧的屏幕外滑动移出，保留应用任务 |
| 顶部内容区 | 展示视频或手动置顶任务，不展示空小窗和「＋」样式 |
| 置顶按钮 | 主窗应用为竖屏时禁用，横屏且满足接入条件时启用 |
| 快捷应用 | 绿色小点只代表工作区主窗或小窗中的应用；手动固定顺序优先 |
| 快捷应用编辑 | 设置页切换开关与调整顺序即时保存，不设置取消和保存按钮 |
| 快捷栏管理列表 | 应用名与行尾开关分开布局，复用农历设置的 `WorkspaceSwitch`；启用项按固定顺序置顶，搜索结果同样置顶，设置页即时保存 |
| 文件与剪贴板列表 | 行间留6dp间隔并使用独立浅底卡片；同页行高一致，默认68dp并随大字体统一增高；文件名一行、剪贴板两行，超长省略，完整载荷保留 |
| 剪贴板文字 | 单击：若能确认当前输入框与焦点窗口则请求粘贴，否则打开选词页；长按：直接拖曳全文；多选模式下单击只切换选中状态 |

拖曳卡片按深浅色分别绘制可读底色，保留淡蓝外缘和箭头。原生文件用单行省略的短横卡片；多选保留叠卡与数量角标。停留到不兼容入口时说明不支持当前内容，不产生可投递选中态。目标切换震动至少间隔90毫秒，避免快速横扫和自动滚动连续震动。

边缘滚动保留350毫秒停留门槛，按深入边缘的程度及停留时长渐进加速；到达列表端点或离开区域停止。系统关闭动画时，分享栏、悬停放大和内容页切换直接进入最终状态，不能留下半透明页或中间投影。

内容、选词、主窗截图和标准文字入口通过 `WorkspacePopupStyle.dragWindow` 统一设置来源窗口的可触摸状态、窗口透明度和模糊；拖曳隐藏整个窗口，取消恢复。不能只隐藏 DecorView 内容而保留磨砂底板。
| 内容弹窗关闭 | 点击弹窗外关闭主面板及预览；非焦点主面板显式接收外部触摸，不以全屏透明触摸区阻塞顶栏与小窗；历史设置仅行尾开关切换，空白不触发 |
| 快捷栏配置入口 | 仅在设置中管理快捷应用与分享入口，内容弹窗不显示配置入口，顶栏长按不打开编辑器 |
| 文件页 | 只展示文件列表与元信息；长按拖曳，多选后可批量分享，不打开文件预览 |
| 主窗内容补充 | 支持标准文字选区菜单「拖曳到一步」；设置旁的四角截图按钮的「截取主窗图片」由用户框选画面后长按拖出 |
| 视频遮挡顶栏 | 内容拖曳时临时显示独立分享条，拖曳结束移除，不改变视频或顶部任务的位置 |
| 设置选项 | 真实保存项与选中态一致，自动保存时明确写「选择后自动保存」 |

统一使用「工作区」「主窗」「小窗」「顶栏」。用户说明描述操作与结果，不展示 Binder、Surface、事务等实现术语。
图标按钮要有语义描述；隐藏的控件不得继续拦截输入。视频与手动置顶的退出控件复用一致的大小、间距和风格。

## 动画

进退场的主窗缩放和工作区控件使用同一动画时钟。竖屏顶栏沿主窗上边移动，侧栏靠近主窗边缘，正常间距与分隔线随布局落位恢复。

1. 工作区进入、退出使用共享时钟起点和运动规范，主窗与侧栏位移保持对应；加号和应用内容随侧栏整体滑动。
2. 壁纸托底保持物理屏幕坐标，主窗移动期间不得暴露空白或黑色底层。不要用调整速度掩盖几何缺口。
3. 顶部接入先准备目标尺寸和内容帧，再淡入覆盖时间、日期和按钮；退出时同步移除退出控件并淡出恢复原内容。
4. 视频比例变化时按所选 fit / fill 策略裁剪，顶部内容区保持完整遮挡和输入隔离，不能透出或点到下面的快捷应用。
5. 取消、换边、快速连续点击或退出后，旧动画回调不得继续写入新场景。
6. 锁屏与亮屏由统一交接协议控制主窗、顶栏和侧栏显示，不各自启动独立的恢复动画。
7. 分享栏使用 `SHARE_RAIL_MS`（480ms），应用行与分享行按立方体相邻面共棱投影旋转。内容首格仅在应用面显示，分享面从首格起排列分享入口，不预留内容按钮的位置。分享功能图标带蓝色箭头角标，整条分享面使用主题强调色混合底色，命中坐标使用同一投影矩阵的逆变换。

拖曳卡片复用 `ContentDragShadow`：较低透明度的玻璃纸片与箭头使用连续轮廓，外缘描淡天蓝色细线、下方保留柔和阴影。图片展示缩略图，文字与文件展示有界摘要；箭头始终朝上，触点保持在卡片下方。顶栏命中直接使用自绘卡片的物理箭头偏移，不再套用来源应用的私有兼容缩放。拖曳时的透明接收区域不绘制顶栏，因此不替代原有立方体动画。

内容中的所有二级页统一经 `ContentPanelLayout.push/pop` 在同一个窗口内切换：图片预览、识字后的选词、剪贴板选词和历史设置均保持一级页大小、圆角和材质，不增加第二层磨砂窗口。内页移除背景、内边距时也必须清除自己的Outline和圆角裁切，只由外层弹窗裁切；不能让内页28dp轮廓再次切到操作按钮，造成外侧圆角变大。进入时从右侧滑入，顶部返回后恢复一级分类、滚动位置和多选状态。原页保留在视图树中但隐藏，二级内容独占可用高度；选词页不再显示底部预览或原文，词块区独立滚动并使用剩余高度。按钮继续使用公共实心控件；词块使用透明描边、较小圆角及浅蓝选中底，避免与顶部操作按钮混淆。

应用内手势统一为原有长按菜单优先；系统提取先保留候选，长按超出系统阈值150毫秒后明确移动才提起，原地松手不启动拖曳。双指停留进入选词或截图识字兜底，捏合、移动或任一手指抬起取消未执行的兜底。已有原生拖曳开始立即撤销待弹出的分词。同来源窗口及同应用小窗松手默认取消；顶栏明确选择的分享入口不受同包取消限制。文件页仍不预览文件。

分页使用360ms轻微回弹滑块与240ms同向内容过渡；布局没有变化时不得取消滑块动画；空状态位于内容区域中央。一级、二级、选区入口和截取页面的操作按钮复用 `WorkspacePopupStyle.action/styleAction/actionCell`：实际高度44dp、圆角10dp、字体14sp、行内上下边距各3dp；行高按内容展开，不从44dp按钮高度中扣除边距。词块长按仍拖出完整选区，不依赖底部预览文字。标准「拖曳到一步」窗口复用相同尺寸、磨砂材质、标题返回按钮与拖曳隐藏／恢复逻辑，不单独使用420×340dp布局。图片与文字拖曳卡为100dp宽的方形内容区，文件卡168dp宽、单行省略；图片保持比例居中裁切。顶栏分享标题优先在19sp至11sp间缩小，再启用跑马灯。分享角标和应用运行圆点随主窗左右位置镜像。

弹窗只模糊自己的圆角背景；系统禁用模糊或平台兼容失败时使用不透明主题底色，避免下层文字透出。`WindowGlassCompat` 仅处理本模块创建的浮动窗口，不改变来源应用主题。拖曳 Surface 的模糊仅在真实会话内设置，结束随原生影子释放。

近期图片仅展示系统媒体库（MediaStore）中的图片。用户导入的图片在最近文件页可取用。近期图片按网格实际像素请求有界缩略图，预览页单独解码最长2048px的图片，不放大160px缩略图充当清晰预览。工作区内其他应用发起的标准纯文字全局拖曳，可在系统入口替换为同一个卡片绘制器；不改变原文字、来源触摸流或投递权限。
8. 内容拖曳影子使用白框缩略卡与顶部三角指针，指针尖端对应真实投递坐标；文字、文件显示摘要，多选显示数量。命中分享入口时放大至1.14倍并轻微回弹，离开或结束时恢复，不逐帧重启动画。

系统提交协议见[系统与平台规范](系统与平台规范.md)。视图动画结束不等于原生窗口事务已经提交。

## 刷新与资源

分享栏的应用入口使用接收组件提供的图标；内置操作使用 `ShareActionIcon` 的统一蓝色功能图标，不借用默认地图或浏览器图标。管理页保留失效的已选入口供关闭，注明不可用原因；拖曳期间隐藏缺少接收应用的入口，已安装但不支持当前内容的入口保持位置并置灰。显式关闭全部入口后不恢复默认列表。

一次有效拖曳开始使用系统 `DRAG_START` 轻触反馈；重复开始通知与位置更新不重复震动，反馈遵循系统设置。目标命中仍使用原有轻触反馈。小窗停留650ms后仅提升当前绑定的同用户既有任务，离开、隐藏或绑定变化取消旧回调；不因经过小窗而自动启动应用。

「暂存」为内容面板第四页，沿用相同的列表、选词与图片预览组件，选择及滚动位置独立保存。移除暂存不删除系统原文件，也不立即撤销已交付接收方的读取权限。不保留「上次分享」按钮、页面或载荷缓存。

`ChromeWarmup` 在主线程空闲时准备未挂载的顶栏，覆盖时钟、日期、图标与布局。只做一次最大 512×512 的软件预绘制并立即回收临时位图；硬件图标不支持软件绘制时保留测量结果。首次使用绑定真实窗口 Context 和监听器，之后不补货；用户、字体、语言、深浅色及尺寸不匹配时重新创建。预热不注册时钟广播、媒体回调或刷新计时器。

预热视图的操作回调必须在点击时读取当前监听器，不能用绑定方法引用保存预热监听器。回归测试须执行真实按钮构造与点击回调，单独验证缓存字段已替换不足以证明按钮可用。

- 已打开标记合并任务变化事件后刷新，稳定时每 30 秒兜底；隐藏、锁屏和 detach 时取消调度。
- 应用列表、壁纸和统计查询复用已有异步加载及缓存，不放入绘制方法或每帧回调。
- 配置变化更新现有视图；关闭弹窗时恢复其借用的层级、灵动岛显示状态和输入资源。
- 新控件必须能适应字体缩放、长应用名、深浅色与手机／平板布局；不以裁掉文字解决开关挤压。

## 验收

检查深浅色、左右布局、横竖屏、长文本和字体缩放。连续进入／退出、快速交换、锁屏解锁、视频尺寸变化及弹窗中截图时，画面和输入都必须一致。
离线绘制或流程测试不能替代真机逐帧和触摸验证；个人截图与设备日志仅放在被忽略的本地目录。

顶栏六个按钮左右各三个，常见屏宽单格触摸区48dp、窄屏回退38dp；四角截图按钮紧邻设置，中央留给标题。内容操作按钮的触摸区为48dp，图标视觉尺寸保持不变。内容首格与应用首格的中心距为50dp，立方体投影使用真实布局位置。内容与内置分享图标使用 n=3 超椭圆外缘；描边图案优先使用独立线段，避免 OEM 将描边圆角矩形绘成实心。

应用行与分享栏底边贴齐顶栏窗口下沿，不额外保留8dp外侧空白；正常空间下栏高52dp、图标38dp，留白放在栏内。分享面的黄绿色颗粒纹理按参考截图重绘，使用一次生成的64×64不透明平铺位图，不是官方开源原贴图；背景与整条分享面共用立方体变换，普通应用行保持原有背景。视频覆盖场景的独立分享栏也使用52dp高度和相同底纹，不增加后台绘制或定时刷新。

快捷应用与分享入口的设置子页使用 `ShortcutSettingsContent`，沿用外层设置的20dp边距、16dp白／深色卡片、16sp标题与12sp说明；不复用弹窗外框、重复标题和保存按钮。

内容拖出时除隐藏装饰视图，还将源窗口 alpha 设为0并关闭背景模糊；取消时恢复两级窗口的输入、透明度与玻璃，不能留下空白磨砂层。自有影子靠近可用内容区域底边时向下指向真实触点，离开底部以回差恢复朝上；文字由原生编辑器处理 DROP，不向未经验证的输入目标注入粘贴。
