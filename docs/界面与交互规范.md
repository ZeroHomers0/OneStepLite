# 界面与交互规范

适用于工作区、顶栏、小窗、视频呈现、设置和内容面板。用户步骤见 [README](../README.md)，任务与系统输入约束见 [系统与平台规范](系统与平台规范.md)。

## 公共组件

| 区域 | 复用组件 |
| --- | --- |
| 工作区外观 | `WorkspaceChrome`、`HyperOsStyle`、`WorkspaceDividers` |
| 顶栏与快捷应用 | `TopBar`、`WorkspaceClock`、`IconButton`、`QuickAppRail` |
| 设置与图示 | `WorkspaceSettingsPage`、`WorkspaceSwitch`、`EntryGestureDiagram`、`SwapModeDiagram`、`VideoModeDiagram` |
| 快捷应用与分享入口管理 | `ShortcutManagementPage`、`ShortcutSettingsContent`、`PinnedAppEditor` |
| 顶部内容 | `TopPresentationController`、`VideoPane`、`TopTaskPane` |
| 内容界面 | `ContentPanelLayout`、`WorkspacePopupStyle`、`WordSelectionPane` |
| 拖曳呈现 | `ContentDragShadow`、`ShareWorkspace`、`ShareTargetButton` |

同类界面共用控件、色板、状态反馈和动画。视觉尺寸使用 dp，文字使用 sp，挖孔、系统栏、窗口方向和屏幕边界由现有几何计算提供。深浅色同时更新壁纸底板、磨砂、标题和图标对比色。

## 工作区、顶栏与小窗

- 空小窗显示可点击的加号，真实任务出现后立即隐藏。加号和内容随小窗位移，壁纸底板固定在屏幕坐标。
- 有内容的小窗点按与主窗交换，长按拖到另一个有内容的小窗交换两者位置，未命中时取消。向所在侧的屏幕外滑动可移出小窗。拖动快捷应用到空小窗使用高亮作为落点反馈。
- 按钮换边和「随应用切换位置」期间保持应用栏亮度和置顶按钮外观，过渡阶段拦截触摸，提交后按实际主窗状态刷新。固定小窗换位的双方同时移动，任一侧表面不可用时双方直接落位。
- 顶栏六个操作图标共用 24 单位画布、3～21 视觉边界和 2.1 线宽。每侧三个图标，常见触摸区 48dp，窄屏回退到 38dp。四角截图紧邻设置。
- 应用栏与分享栏图标均为 38dp，内容首格为 34dp。底部贴齐栏边，普通栏和独立分享栏高 52dp。应用图标按原始图样绘制，绿点只标记工作区内的应用，暂不可判定时保留上次状态。
- 视频与手动置顶控件共用 40dp 触摸区、20dp 视觉底板及右下角对齐。置顶按钮按页面横屏能力及导航应用准入更新，不可用时保持置灰，提示使用「主窗」「顶栏」等产品术语。

## 设置、管理页与图示

- 设置项标题 16sp、说明 12sp，文字与开关间距 16dp。可自动保存的选择即时写入，搜索页保持已启用项的排序，并用行尾开关显示当前选择。外观设置中的时间、日期、农历分别控制顶栏时钟对应行；日期关闭时农历行不显示，时间和日期都关闭时时钟不参与显示。
- 管理快捷应用和分享入口使用设置外层的 20dp 边距、16dp 卡片与配色。首页后台预取各自的列表，完成时直接展示。短于 300 毫秒的等待无需显示加载文字。返回和配置重建后隔离迟到的界面回调，保存由各类配置各自串行处理。
- 手势、交换方式、横屏显示和拖入空小窗图示共用 206dp 图高和同一绘制语言。README 的四组图复用应用当前绘制代码。设置选中态表现实际保存值。当某个手势不可用时，文案单独说明回退。
- 内容分享、快捷应用与分享入口分别走各自的设置入口。隐藏的控件不继续拦截输入。所有可操作图标应有无障碍描述；开关和可切换管理行应向无障碍服务报告标题、状态和不可用原因，整行点击与行尾开关保持同一结果。
- 设置与管理页继续复用系统 Settings 资源、边到边 Insets、预测返回和现有 HyperOS 卡片语言；现代化取舍及未采用项见 [设置与管理页现代化评估](设置与管理页现代化评估.md)。

## 内容面板与子页

- 内容面板包含图片、文件、剪贴板、暂存四类。分页使用同一水平切换，读取、清空和移除只作用于当前类别。返回时恢复原分类、滚动位置和多选状态。
- 一级与二级页复用同一外层窗口和磨砂容器。图片预览、选词和剪贴板设置用 `ContentPanelLayout.push/pop` 切换，内页移除自己的圆角裁切，由外层统一裁切。
- `WorkspacePopupStyle` 统一最大宽 360dp、最大高 500dp 或屏高 60%、14dp 内边距与 28dp 圆角。系统模糊不可用时使用不透明主题底色。标题 16sp，正文、菜单与动作 14sp，辅助文字 12sp，条目元数据 11sp。
- 返回图标与标题同一行垂直居中、无底色，保留完整触摸区。标题右侧放当前页的必要操作，更多使用竖三点。公共实心按钮高 44dp、圆角 10dp，行内上下各留 3dp。
- 图片按三列展示，间距 4dp、圆角 8dp，无障碍描述包含时间和选择状态。文件只显示摘要和元数据，长按可以分享。剪贴板纯文字单击按可用焦点决定粘贴或进入选词，多选模式下单击切换选择。暂存移除只影响暂存记录。
- 暂存成功展示结果反馈。识别失败或暂不可用的说明留在当前界面。图片搜索页只保留返回和右侧图标重试。

## 拖曳与投递反馈

- 文字和图片影子沿用 100dp 短卡，文件卡为 168dp。箭头朝向实际投递点，命中按箭头位置判断。文件保持单行摘要，多选显示数量。
- 分享栏沿用 480 毫秒立方体翻转，应用面含内容首格，分享面从第一项连续排列。内容拖出时隐藏源窗口的画面、背景模糊和触摸区，取消后恢复。
- 命中分享入口时放大至 1.14 倍并轻微回弹，退出恢复，移动帧之间不重启动画。拖曳开始只反馈一次触觉。目标切换震动间隔至少 90 毫秒。
- 边缘滚动按箭头或卡片与边缘的关系启动候选，连续停留 150 毫秒后渐进滚动。离开边缘或到达端点停止。
- 禁用项保持可辨认状态。不兼容载荷说明原因，缺少接收应用的入口在管理页说明。显示分享成功、失败和暂存结果应区分，系统启动接收页只代表交付到页面。
- 单指提取保留应用长按菜单，候选达到移动门槛才启动原生拖曳，原地松手取消。双指可进入选词或图片预览，截图识字排除状态栏。同来源或同应用小窗松手默认取消，明确命中分享栏则按所选入口处理。

## 动画与验收

- 工作区进退场、换边、任务交换和壁纸露出遵循共享动画时钟。锁屏或新场景取消旧回调，系统关闭动画时直接提交最终布局。动画结束与原生窗口事务提交分开校验。
- 顶部内容在目标尺寸和画面就绪后淡入，退出控件同步退场。透明区域不能点击穿透到被覆盖的快捷应用。
- 验收至少覆盖深浅色、左右布局、手机与平板、横竖屏、长文本和字体缩放。对换边和小窗换位复测空位、连续操作和取消。对拖曳复测不同类型的内容、设备边缘命中、同来源松手及投递失败。
- 离线绘制用于检查布局、色板和图示。真实动画、触摸和视频合成需要 HyperOS 真机确认，个人截图和日志放在被忽略的目录。
